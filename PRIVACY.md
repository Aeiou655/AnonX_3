# Privacy Policy — SUIII WIII Music Bot

**Effective date:** August 12, 2026  
**Telegram Bot:** [@suiiimusic_bot](https://t.me/suiiimusic_bot)  
**Contact / Maintainer:** [@khantpainghtet](https://t.me/khantpainghtet)

This Privacy Policy explains how **SUIII WIII Music Bot** ("the Bot", "we", "our", or "us") processes information when users interact with the Telegram bot, use music/video playback features, add the Bot to groups or channels, use Telegram Voice Chat functions, or open related Mini App features.

## 1. What the Bot Does

SUIII WIII Music Bot provides Telegram music and video functionality, including media search, audio playback, video playback, Voice Chat streaming, queue management, pause/resume/skip/stop controls, direct media streaming, media prefetching/caching, group-specific settings, administrative functions, automatic-response/learning features where enabled, and operational diagnostics.

## 2. Information We May Process

Depending on how the Bot is used, Telegram may provide information such as:

- Telegram numeric user ID
- Username and display name
- Chat, group or channel ID and name
- Message ID and reply/callback context
- Commands sent to the Bot
- Search queries, song/video names and URLs submitted to the Bot
- Media/video identifiers and playback selections
- Group permissions or administrator status relevant to Bot features
- Bot/group configuration and playback state

The Bot does **not** require a user's Telegram password or two-factor authentication password for normal operation.

## 3. Messages and Auto-Learn Processing

Where automatic-response or learning functionality is enabled, the Bot may process message text or a normalized phrase together with the relevant Telegram user ID and chat ID. It may also maintain observation counts or associated response data so the feature can recognize repeated phrases and provide configured automated responses.

This data is used only for Bot functionality, moderation, automatic responses, service operation and maintenance. It is not intended to be used to build unrelated commercial datasets.

## 4. Music and Video Requests

When a user requests media, the Bot may process:

- Search keywords
- Song or artist names
- Video names
- Submitted media URLs
- YouTube/video IDs
- Requested audio/video mode
- Media title, duration, format and quality information
- Playback and queue state

These details are used to locate, resolve and play the requested media.

## 5. Media Processing and Third-Party Services

To provide playback, the Bot may communicate with Telegram, YouTube and media-delivery infrastructure and may use server-side components such as yt-dlp, FFmpeg, Deno and PyTgCalls.

The Bot may send technically required search terms, media identifiers, URLs, request metadata and connection information to external services in order to locate and stream requested media. Those third-party services operate under their own terms and privacy policies.

Server-side cookies, tokens, API credentials, assistant-session credentials and similar service credentials belong to the Bot infrastructure and are not obtained from ordinary users as Telegram login credentials.

## 6. Telegram Voice Chat

For Voice Chat playback, the Bot may process information such as:

- Telegram chat ID
- Voice Chat connection state
- Assistant-account state
- Join/leave and mute/unmute state
- Current media ID
- Audio/video mode
- Queue and stream state

The service may use a Telegram assistant account to join Voice Chats and transmit requested audio/video where required.

## 7. Queue, Playback and Temporary State

The Bot may temporarily store or cache information needed to control playback, including the current track, queue position, media identifier, playback mode, requesting user ID, chat ID, pause/resume state, next-track information and stream state.

This information is used to provide queueing, auto-next, pause, resume, skip, stop, cleanup and related playback functions.

## 8. Prefetching, Cache and Media Metadata

To reduce startup delay and improve reliability, the Bot may prefetch or cache media or media information in the background. This can include resolved media URLs, media identifiers, titles, duration, thumbnails, temporary files, technical format information and next-track data.

Temporary cache entries may expire, be overwritten, be deleted during cleanup, or disappear after a restart.

## 9. Database and Persistent Settings

The Bot uses database/cache systems for operational data that may include:

- User or group Bot settings
- Administrative configuration
- Owner/sudo configuration
- Playback-related settings
- Feature state
- Automatic-response/learning data where enabled
- Cached operational information

Persistent records are retained only while reasonably necessary for the feature or service purpose for which they are used, subject to applicable legal requirements.

## 10. Operational Logs

The Bot creates technical logs for debugging, performance optimization, reliability, security and abuse prevention. Logs may contain:

- Date and time
- Telegram chat ID
- Telegram user ID in operations where it is required
- Commands or search queries
- Media/video ID
- Playback mode and status
- Queue/cache state
- Request or trace identifiers
- Voice Chat state
- Error information
- Media-source information
- Performance timing information

Performance logs may record milestones such as command receipt, search completion, source resolution, Voice Chat connection, FFmpeg/media startup, stream attachment, first audio/video frame and playback completion/failure.

We do not intentionally log passwords, Telegram login credentials or private API secrets belonging to users.

## 11. Mini App

If the SUIII WIII Mini App is used, Telegram may provide Mini App initialization/session information and basic Telegram account context such as user ID, display name, username, language or chat/session information, depending on Telegram's platform behavior and the feature being used.

This information is processed to authenticate the Telegram Mini App session, provide requested functions, personalize service behavior where applicable and protect the service from unauthorized requests.

## 12. Data Sharing

We do **not sell users' personal data**.

Information may be processed by or shared with service providers only where reasonably necessary to provide the Bot, including Telegram, hosting/server providers, media/search services and media-delivery infrastructure. Information may also be disclosed where required by applicable law or a valid legal request.

## 13. Data Retention

Temporary playback buffers, stream state, expiring media URLs, cached media and similar operational data may be removed when playback ends, when a cache expires, during cleanup or after service restart.

Persistent settings, group configuration, learning/automatic-response data and necessary database records may remain until deleted, reset, no longer required or the relevant feature is removed.

Diagnostic logs are retained only for a period reasonably necessary for debugging, security, abuse prevention and service maintenance.

## 14. Data Deletion and User Choices

Users may stop using or block the Bot at any time. Group administrators may remove the Bot from a group or channel to stop future Bot processing there.

Users may also request deletion of personal information controlled by SUIII WIII Music Bot. Where technically possible and legally permitted, user-related data that is no longer required for operation will be removed.

Some temporary information may already have been automatically deleted because it existed only in short-lived memory, cache or playback state.

## 15. Security

Reasonable technical and organizational measures are used to protect Bot infrastructure and service data. Sensitive service credentials such as Bot tokens, API credentials, Telegram assistant-session credentials and media-service credentials are not intended to be exposed to ordinary users.

No internet-connected service can guarantee absolute security.

## 16. Information Users Should Not Send

Users should not send the Bot:

- Telegram passwords
- Two-factor authentication passwords
- Banking or payment passwords/PINs
- Private API keys or tokens
- Telegram session files
- Email passwords or other private credentials

These are not required for normal music/video playback.

## 17. Abuse Prevention

Technical identifiers, logs and request information may be processed where necessary to detect misuse, prevent spam or abuse, enforce service/resource limits, investigate failures and protect Bot infrastructure.

## 18. Children's Privacy

The Bot is not designed to intentionally collect unnecessary sensitive personal information from children. Users should comply with Telegram's applicable age requirements and local law.

## 19. Telegram's Separate Role

SUIII WIII Music Bot is an independent third-party service operating through Telegram and is not Telegram Messenger Inc. Telegram independently processes information under Telegram's own Terms of Service and Privacy Policy.

This document covers data processing performed by **SUIII WIII Music Bot**, not Telegram's independent processing.

## 20. Changes to This Policy

The Bot is actively developed. This Privacy Policy may be updated if Bot features, storage systems, Mini App behavior, third-party integrations or legal requirements change.

Material changes affecting how personal data is collected, used, stored or shared should be reflected in an updated version of this policy.
