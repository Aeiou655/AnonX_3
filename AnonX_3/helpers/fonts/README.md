# Thumbnail Fonts

Bundled fonts here are used by `AnonX.helpers._thumbnails` so generated
now-playing cards can render Myanmar text even when the deployment host does
not have Myanmar system fonts installed.

- `Pyidaungsu-Regular.ttf` (preferred Myanmar font for `THUMB_BOT_NAME`)
- `Pyidaungsu-Bold.ttf` (preferred bold Myanmar font for `THUMB_BOT_NAME`)

Source (Pyidaungsu): https://github.com/mcfnlp/Pyidaungsu

License: SIL Open Font License 1.1.
